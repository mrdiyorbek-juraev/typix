# @typix-editor/extension-tailwind

## 5.0.1

### Patch Changes

- Patch release 5.0.1 — minor fixes across cli, core, react, utils, and extensions.

## 5.0.0

### Major Changes

- **Initial release.** Maps Lexical's internal theme keys to Tailwind utility classes — drop in instead of `defaultTheme` to render the editor with Tailwind classes on every node instead of the `.typix-*` CSS vocabulary.
- Useful when you want full visual control via Tailwind utilities (and don't want to import the design-system CSS at all).
