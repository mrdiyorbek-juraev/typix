title: Typix Editor

Typix is a headless, extension-based rich-text editor framework for React,
built on Meta's [Lexical](https://lexical.dev). You install only the
extensions you need, own the UI source via the CLI, and stay close to
Lexical when you need to.

## Why Typix

- **Headless** — Editor logic and rendering are decoupled. Nothing forces
  a particular look.
- **Extension-based** — 25 first-party extensions for marks, blocks,
  toolbars, mentions, code, tables, images, AI helpers, and more. Install
  only what you use.
- **You own the UI** — [typix ui add](/docs/getting-started/cli) copies
  React components into your repo (shadcn-style). Customize anything;
  nothing is locked inside `node_modules`.
- **Type-safe** — Extensions augment a global command interface; the
  [editor.chain()](/docs/core/typix-editor) builder is typed per installed
  extension.
- **Built on Lexical** — Battle-tested engine. Direct
  [editor.lexical](/docs/guides/lexical-interop) access whenever you need
  a raw Lexical command.
