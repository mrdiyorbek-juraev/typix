The basic link extension — adds the link node type and commands. Pair
with [Auto Link](/docs/extensions/auto-link) for URL-as-you-type and
[Floating Link](/docs/extensions/floating-link) for the inline editor UI.

## Install

```bash
pnpm add @typix-editor/extension-link
```
