---
title: Code Highlight (Shiki)
description: Syntax highlighting for code blocks via Shiki (TextMate grammars)
---

Adds Shiki-powered syntax highlighting to your code blocks. Same engine
VS Code uses, so output matches your editor's theme. Requires the
[Code Block](/docs/extensions/code-block) extension as the host
container.

## Install

```bash
pnpm add @typix-editor/extension-code-highlight-shiki
```

## Tradeoff vs Prism

| | Prism | Shiki |
|---|---|---|
| Bundle size | small | larger (TextMate grammars + WASM) |
| Theme fidelity | OK | matches VS Code exactly |
| Lazy load | easy | already lazy |
| Best for | general projects | code-heavy docs sites |

Install one, not both.
