---
title: Max Length
description: Hard input cap — blocks typing beyond a maximum character count
---

Prevents the user from typing beyond a configured character count.
Unlike [Character Limit](/docs/extensions/character-limit) which just
shows a counter, Max Length actively blocks input.

## Install

```bash
pnpm add @typix-editor/extension-max-length
```

## Config

| Option | Type | Default | Description |
|---|---|---|---|
| `maxLength` | `number` | required | Hard upper bound on character count. |
