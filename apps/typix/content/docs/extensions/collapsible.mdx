---
title: Collapsible
description: Collapsible sections (details/summary) inside the editor
---

Adds collapsible/expandable content blocks — a title that toggles
visibility of its body. Native HTML `<details>` semantics.

## Install

```bash
pnpm add @typix-editor/extension-collapsible
```

## Live demo

<ComponentPreview name="collapsible" />

## Insert programmatically

```tsx
import { INSERT_COLLAPSIBLE_COMMAND } from "@typix-editor/extension-collapsible";

editor.lexical.dispatchCommand(INSERT_COLLAPSIBLE_COMMAND, undefined);
```

## Node helpers

```tsx
import {
  $createCollapsibleContainerNode,
  $createCollapsibleTitleNode,
  $createCollapsibleContentNode,
  $isCollapsibleContainerNode,
} from "@typix-editor/extension-collapsible";
```

Use these inside `editor.lexical.update(() => ...)` blocks for custom
content insertion.
